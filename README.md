# Power BI AI Features Lab: Decomposition Tree & Forecasting

## About the Project
This project demonstrates the use of built-in AI features in Power BI to analyze data and generate insights. The analysis is based on two datasets:

- A cereals dataset to explore product performance using the Decomposition Tree visual  
- A coffee sales dataset to identify trends and generate forecasts using time series analysis  

The goal is to apply AI-assisted tools to move beyond basic reporting and support deeper analytical thinking.

## Project Highlights

### Decomposition Tree Analysis (Cereals Dataset)
- Built a Decomposition Tree to analyze average cereal ratings  
- Used AI splits to identify key drivers of high and low ratings  
- Explored relationships across manufacturer, sugar, fiber, and protein  

**Key Insight:**  
Lower sugar and higher fiber cereals tend to have higher ratings  

---

### Sales Forecasting (Coffee Sales Dataset)
- Created a time series line chart of daily total sales  
- Applied a 30-day forecast with 95% confidence interval  
- Used weekly seasonality (7-day cycle)  

**Key Insight:**  
Sales follow consistent weekly patterns with predictable peak days
